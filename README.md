# NMK11203 Course Hub

## Publish on GitHub Pages
1. Create a repository, for example `nmk11203`.
2. Upload `index.html`, `style.css`, `script.js`, and the `weeks` folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch → main → /(root)**.
5. The site will be available at `https://YOUR-USERNAME.github.io/nmk11203/`.

## Customise the course
Replace every `href="#"` with the real URL for:
- lecture notes
- videos
- Google Forms / quizzes
- laboratory manuals
- assignment submission
- UniMAP LMS resources

The weekly pages in `/weeks/` are reusable templates for Weeks 1–15.
